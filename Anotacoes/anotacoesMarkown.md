- `#` Cria um título.
- `##` Cria um subtítulo.
- `###` Cria um subtítulo menor.
- `**texto**` Deixa o texto em negrito.
- `*texto*` Deixa o texto em itálico.
- `~~texto~~` Deixa o texto riscado.
- `` `texto` `` Mostra o texto como código.
- `>` Cria uma citação.
- `---` Cria uma linha horizontal.
- `-` Cria uma lista.
- `1.` Cria uma lista numerada.
- `- [ ]` Cria uma tarefa não concluída.
- `- [x]` Cria uma tarefa concluída.
- `[texto](link)` Cria um link.
- `![texto](imagem)` Adiciona uma imagem.

## Exemplos

### Títulos

> `# Título principal`  
> `## Subtítulo`  
> `### Título menor`

### Textos

> `**Texto em negrito**` → **Texto em negrito**  
> `*Texto em itálico*` → *Texto em itálico*  
> `~~Texto riscado~~` → ~~Texto riscado~~  
> `` `Código` `` → `Código`

### Listas

> `- HTML`  
> `- CSS`  
> `- JavaScript`

### Lista Numerada

> `1. HTML`  
> `2. CSS`  
> `3. JavaScript`

### Checklist

> `- [x] Estudar HTML`  
> `- [ ] Estudar CSS`  
> `- [ ] Estudar JavaScript`

### Links

> `[GitHub](https://github.com)`

### Imagens

> `![Logo](./img/logo.png)`

### Citação

> `> Essa é uma citação.`

### Linha Horizontal

> `---`

## Código

Para colocar código em uma linha:

> `` `console.log("Olá")` ``

Para colocar várias linhas de código, use três crases:

> ` ```javascript `  
> `console.log("Olá");`  
> ` ``` `

O `javascript` serve para indicar a linguagem usada no código.

## Linguagens

- `javascript` → JavaScript.
- `html` → HTML.
- `css` → CSS.
- `python` → Python.
- `sql` → SQL.
- `json` → JSON.
- `bash` → Terminal/Shell.

## Tabelas

- `|` Separa as colunas.
- `---` Separa o cabeçalho das informações.

### Exemplo

> `| Nome | Idade |`  
> `|------|------:|`  
> `| Tiago | 16 |`  
> `| João | 17 |`

## Links Para Arquivos

- `./` → Indica a pasta atual.
- `../` → Volta uma pasta.

### Exemplo

> `[Documentação](./docs/documentacao.md)`

## HTML no Markdown

Também é possível utilizar HTML dentro de um arquivo Markdown.

### Exemplo

> `<div>`  
> `    <h1>Meu Projeto</h1>`  
> `    <p>Descrição do projeto.</p>`  
> `</div>`

## README

Um README é um arquivo `.md` usado para explicar um projeto.

### Exemplo

> `# 🚀 Meu Projeto`  
>
> `Descrição do projeto.`  
>
> `## Tecnologias`  
>
> `- HTML`  
> `- CSS`  
> `- JavaScript`  
>
> `## Instalação`  
>
> `Explique como instalar o projeto.`  
>
> `## Como usar`  
>
> `Explique como executar o projeto.`  
>
> `## Autor`  
>`
